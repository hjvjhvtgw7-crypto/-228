# NFT Offer Demo Bot

Учебный Telegram-бот для демонстрации объявлений и статусов предложений.
Он не проводит сделки, не передаёт NFT/подарки/деньги и всегда помечает предложения как DEMO.

## Команды
- `/start`
- `/info https://t.me/nft/Demo-1 ru 100 star`
- `/offer https://t.me/nft/Demo-1`

Валюты для демонстрационной записи: `star`, `gra`. Языки: `ru`, `en`.

## Render
1. Создайте Telegram-бота через @BotFather.
2. Загрузите этот проект в приватный GitHub-репозиторий.
3. В Render создайте Web Service из репозитория.
4. Build command: `pip install -r requirements.txt`
5. Start command: `python bot.py`
6. Добавьте переменную окружения `BOT_TOKEN` со значением токена из BotFather.
7. Разверните сервис.

Важно: бесплатные инстансы могут засыпать, а локальная файловая система бесплатного хостинга может быть временной. SQLite-файл может сбрасываться при перезапуске/переразмещении. Для постоянных данных нужна поддерживаемая постоянная база/диск.
